# Changelog

## [Unreleased]

- **Breaking:** the client core and admin calls are rewritten. `New(baseURL, opts...)` with `WithToken`, `WithTokenSource`, `WithOperatorKey`, `WithTenant`, `WithRetry`, `WithHTTPClient`, `WithHeader` and `WithUserAgent` replaces `NewClient(Config)`; `Client.WithTenant` derives a client for another tenant. Health, version, schema, DLQ, pipe-definition and settings-reload calls are methods on `Client`. Failures are `*APIError` (with the server's `code`, `retryable` and `X-Request-Id`), matched with `errors.Is` against `ErrNotFound` and the other sentinels; retries depend on whether resending is safe and honour `Retry-After`. JSON numbers decode as `json.Number`. Go 1.26 is now the minimum. Streaming is being rewritten onto the new core and is absent until then.
- **Breaking:** ingest, queries, pipes and raw SQL are rewritten onto the new core. `Client.From(table)` starts an immutable query builder (`Select`, `SelectAll`, `Where`, `OrderBy`, `GroupBy`, `Limit`, `TimeRange`, `Count`, `Sum`, `Avg`, `Min`, `Max`, `CountDistinct`, `Aggregate`) that ends in `Scan(ctx, &rows)` for structs or maps, or `Fetch(ctx)` for `[]Row`; builder misuse is an error from `Scan`/`Fetch`, not a panic. `Query.Insert` takes a struct, map or slice and always sends NDJSON, so every call returns the per-record `InsertResult`; rejected records also return an `*InsertError`, and `InsertNDJSON` sends a pre-encoded body. `Client.Pipe(name).Param(...).Scan(ctx, &rows)` runs a pipe and `Client.SQL(query)` has `Scan`, `Fetch` and `Exec`. UInt64 and Int64 stay exact. Removed because the server dropped them or never honoured them: the policy endpoints, pipe writers, `CacheTTL` (a no-op) and `not_like` (the server rejects it); the client-side default limit of 1000 is gone, so a query without `Limit` is capped by the server alone. Live queries and pagination return once the server supports them (Wave-RF/WaveHouse#951, Wave-RF/WaveHouse#452).
- Imported, with history, from the `go-sdk` branch of WaveHouse ([Wave-RF/WaveHouse#434](https://github.com/Wave-RF/WaveHouse/pull/434)). Not released yet; the SDK still has to catch up with the current server protocol.
